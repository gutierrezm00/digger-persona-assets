# Digger Persona Assets

Publicly hosted artwork for fictional Digger Discord personas.

Each persona keeps its artwork under `avatars/<persona-id>/`, where the id matches the
entry in `PERSONA_ROSTER` in the Digger repository's `Tools/DiscordComms/src/personas.ts`.
`default.png` is the avatar the comms service uses.

## Director Maribel Voss

Senior Director, Operator Enthusiasm — corporate community management.

- [Default avatar](avatars/maribel-voss/default.png)

## Rig Chief Marek Kovak

Rig Chief, Drill and Hull Maintenance — maintenance bulletins and hazard advisories.

- [Default avatar](avatars/marek-kovak/default.png)

## Dr. Emil Ostrove

Lead Planetologist, Deep Survey — survey findings and strata explainers.

- [Default avatar](avatars/emil-ostrove/default.png) — horizontally mirrored so the core
  sample column sits left of frame.
- [Unflipped original](avatars/emil-ostrove/unflipped.png) — same portrait with the
  signage reading correctly. Use this one anywhere the artwork appears large enough to
  read the labels.

These assets support fictional narrative communications and community announcements.
